# เพิ่มปฏิทินและอีเมล ลงใน Flow A

ทำต่อจาก `docs/flow-a-recipe.md` หลังจาก Flow A ส่งการ์ดได้แล้ว

เพิ่มสองอย่างในกิ่ง **จริง** ของ `CheckSend` ต่อจาก `SendCard`

1. สร้างกิจกรรมในปฏิทินของพนักงาน เห็นได้ทั้งใน Teams และ Outlook
2. ส่งอีเมลแจ้งซ้ำ สำหรับคนที่ไม่ได้เปิด Teams เป็นประจำ

---

## ก่อนเริ่ม เพิ่มสามคอลัมน์ในชีต ผู้เข้าอบรม

| คอลัมน์ | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `เพิ่มปฏิทินแล้ว` | `ไม่ใช่` | กันสร้างกิจกรรมซ้ำทุกวัน |
| `รหัสกิจกรรมปฏิทิน` | ว่าง | เก็บไว้แก้หรือยกเลิกกิจกรรมภายหลัง |
| `ขอยืนยันแล้ว` | `ไม่ใช่` | Flow B ใช้ กันส่งคำขอยืนยันซ้ำ |

**อย่ารัน `migrate.py` ทับไฟล์ที่ใช้งานจริง** ไฟล์บน OneDrive มีข้อมูลที่พิมพ์เอง
และที่ Flow เขียนลงไป การรันสคริปต์จะสร้างไฟล์ใหม่ทับทั้งหมด

เพิ่มด้วยมือใน Excel บนเว็บ คลิกช่องหัวตารางถัดจากคอลัมน์สุดท้าย แล้วพิมพ์ชื่อ
ตารางจะขยายรับคอลัมน์ใหม่เอง จากนั้นพิมพ์ค่าเริ่มต้นแถวแรกแล้วลากลงทั้งคอลัมน์

## ขั้นที่ 1 เงื่อนไขปฏิทิน

ในกิ่ง **จริง** ของ `CheckSend` ต่อจาก `SendCard`
เพิ่ม **การควบคุม → เงื่อนไข** ชื่อ `NeedCalendar`

| ช่อง | ค่า |
|---|---|
| ซ้าย | `fx` แล้ววาง `toLower(string(items('ForEachRow')?['เพิ่มปฏิทินแล้ว']))` |
| ตัวดำเนินการ | ไม่เท่ากับ |
| ขวา | พิมพ์ `true` |

ใช้ ไม่เท่ากับ `ใช่` ช่องที่ปล่อยว่างจึงนับว่ายังไม่ได้เพิ่ม

กิจกรรมต้องสร้างครั้งเดียว ไม่ใช่ทุกครั้งที่แจ้งเตือน
ถ้าไม่เช็คตรงนี้ พนักงานจะได้กิจกรรมซ้ำสองอัน เพราะ Flow A ส่งทั้งรอบ 7 วันและ 1 วัน

## ขั้นที่ 2 สร้างกิจกรรม

ในกิ่ง **จริง** ของ `NeedCalendar`
เพิ่ม **Office 365 Outlook → สร้างเหตุการณ์ (V4)** ชื่อ `CreateEvent`

| ช่อง | ค่า |
|---|---|
| ปฏิทิน | Calendar |
| หัวเรื่อง | `fx` วาง `concat('อบรม ', outputs('Training')?['หัวข้ออบรม'])` |
| เวลาเริ่มต้น | `fx` วาง `outputs('EventStart')` ดูขั้นที่ 3 |
| เวลาสิ้นสุด | `fx` วาง `outputs('EventEnd')` |
| เขตเวลา | `(UTC+07:00) Bangkok, Hanoi, Jakarta` |
| ผู้เข้าร่วมที่จำเป็น | `fx` วาง `outputs('Employee')?['อีเมล Microsoft 365']` |
| ตำแหน่งที่ตั้ง | `fx` วาง `outputs('Training')?['สถานที่']` อบรมออนไลน์จะเป็นลิงก์ Outlook ทำให้กดได้เอง |
| เนื้อความ | ดูด้านล่าง |
| เตือนความจำก่อนเริ่มเป็นนาที | `1440` คือหนึ่งวัน |

ช่อง เนื้อความ

```
หลักสูตร @{outputs('Training')?['หัวข้ออบรม']}
สถาบัน @{outputs('Training')?['สถาบันผู้จัดอบรม']}
วิทยากร @{outputs('Training')?['วิทยากร']}
รูปแบบ @{outputs('Training')?['รูปแบบ']}
ช่วงเวลา @{outputs('Training')?['ช่วงเวลา']}
ชั่วโมงรวม @{if(empty(outputs('Training')?['ชั่วโมงรวม']),'-',concat(outputs('Training')?['ชั่วโมงรวม'],' ชั่วโมง'))}

กิจกรรมนี้สร้างโดยระบบแจ้งเตือนการอบรม ไม่ต้องตอบรับ
```

## ขั้นที่ 3 คำนวณเวลาเริ่มและสิ้นสุด

ต้องทำ **ก่อน** `CreateEvent` วางไว้ต่อจาก `ThaiDate` ก็ได้

ไฟล์เก็บแค่วันที่ ส่วนเวลาอยู่ในช่อง `ช่วงเวลา` ซึ่งเป็นข้อความอิสระอย่าง
`09.00-16.30 น.` แปลงเป็นเวลาจริงไม่ได้ทุกกรณี จึงตั้งเป็นทั้งวันไปก่อน

action **เขียน** ชื่อ `EventStart`

```
concat(formatDateTime(outputs('Training')?['วันเริ่ม'],'yyyy-MM-dd'),'T09:00:00')
```

action **เขียน** ชื่อ `EventEnd`

```
concat(formatDateTime(outputs('Training')?['วันจบ'],'yyyy-MM-dd'),'T17:00:00')
```

ถ้าวันหลังอยากให้ตรงเวลาจริง ต้องเพิ่มคอลัมน์ `เวลาเริ่ม` และ `เวลาจบ`
แยกเป็นตัวเลขในชีต หลักสูตร แล้วเปลี่ยนสองสูตรนี้ให้อ่านจากคอลัมน์นั้น

## ขั้นที่ 4 บันทึกว่าเพิ่มปฏิทินแล้ว

ต่อจาก `CreateEvent` ในกิ่งเดียวกัน
เพิ่ม **Excel Online (Business) → Update a row** ชื่อ `MarkCalendar`

| ช่อง | ค่า |
|---|---|
| Location, Document Library, File | เหมือน `MarkD7` |
| Table | Enrollments |
| Key Column | รหัสการลงทะเบียน |
| Key Value | `fx` วาง `items('ForEachRow')?['รหัสการลงทะเบียน']` |
| เพิ่มปฏิทินแล้ว | `fx` `true` |
| รหัสกิจกรรมปฏิทิน | `fx` วาง `body('CreateEvent')?['id']` |

ช่องอื่นเว้นว่างทั้งหมด

## ขั้นที่ 5 ส่งอีเมล

กลับมาที่กิ่ง **จริง** ของ `CheckSend` ต่อจาก `NeedCalendar`
ไม่ใช่ข้างในกิ่งของ `NeedCalendar`

อีเมลต้องส่งทุกรอบแจ้งเตือน ต่างจากปฏิทินที่สร้างครั้งเดียว

เพิ่ม **Office 365 Outlook → ส่งอีเมล (V2)** ชื่อ `SendMail`

| ช่อง | ค่า |
|---|---|
| ถึง | `fx` วาง `outputs('Employee')?['อีเมล Microsoft 365']` |
| หัวเรื่อง | `fx` วาง `concat(if(equals(outputs('Stage'),'D7'),'แจ้งเตือนล่วงหน้า 7 วัน ','แจ้งเตือนพรุ่งนี้ '), outputs('Training')?['หัวข้ออบรม'])` |

ช่อง เนื้อความ กดปุ่ม `</>` เพื่อสลับเป็นโหมด HTML แล้ววาง


## ทดสอบ

ตั้ง `วันเริ่ม` ของหลักสูตรทดสอบเป็นวันนี้ + 7 พอดี ไม่งั้น `Stage` ว่างและทั้งกิ่งถูกข้ามเงียบ ๆ

ล้างค่าในไฟล์ก่อน ที่แถว `ENR-2569-0256`

| คอลัมน์ | ตั้งเป็น |
|---|---|
| แจ้งล่วงหน้า 7 วันแล้ว | `ไม่ใช่` |
| เพิ่มปฏิทินแล้ว | `ไม่ใช่` |
| รหัสกิจกรรมปฏิทิน | ลบให้ว่าง |

แล้วสั่งรัน

| ต้องเห็น | ที่ไหน |
|---|---|
| การ์ด | แชท Flow bot ใน Teams |
| อีเมล | กล่องจดหมาย |
| กิจกรรม `อบรม Test` | ปฏิทินใน Teams หรือ Outlook ตรงวันเริ่ม-วันจบ เวลา 09:00-17:00 |
| `เพิ่มปฏิทินแล้ว` เป็น `ใช่` | ในไฟล์ |
| `รหัสกิจกรรมปฏิทิน` มีค่ายาว ๆ | ในไฟล์ |

รอบสอง เปลี่ยนแค่ `แจ้งล่วงหน้า 7 วันแล้ว` กลับเป็น `ไม่ใช่` ปล่อย `เพิ่มปฏิทินแล้ว` เป็น `ใช่`
แล้วรันอีกครั้ง ต้องได้การ์ดและอีเมลใหม่ แต่ปฏิทินยังมีกิจกรรมเดียว

การรันซ้ำเฉย ๆ พิสูจน์อะไรไม่ได้ เพราะ `แจ้งล่วงหน้า 7 วันแล้ว` เป็น `ใช่` แล้ว
ทั้งกิ่งจึงถูกข้ามก่อนถึง `NeedCalendar` รอบสองแบบนี้เลียนแบบรอบแจ้งเตือน 1 วันจริง
