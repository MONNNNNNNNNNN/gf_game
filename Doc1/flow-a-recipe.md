# สูตรสร้าง Flow A ทีละขั้น คัดลอกวางได้เลย

Flow A คือตัวแจ้งเตือนล่วงหน้า 7 วัน และ 1 วัน สร้างตัวนี้ก่อนตัวอื่นทั้งหมด
เพราะเป็นตัวที่ง่ายที่สุดและเห็นผลเร็วที่สุด

เอกสารนี้เป็นสูตรสำเร็จ ถ้าอยากเข้าใจเหตุผลเบื้องหลังให้ดู
`docs/flow-build-guide.md` หัวข้อ 5

---

## กฎการตั้งชื่อ ต้องทำตามเป๊ะ

ตั้งชื่อทุก action เป็น **อักษรละตินไม่มีเว้นวรรค** ตามที่ระบุในเอกสารนี้

สูตรอ้างถึง action ด้วยชื่อ ถ้าตั้งชื่อเป็นภาษาไทยหรือมีเว้นวรรค
สูตรที่คัดลอกไปจะหา action ไม่เจอ และขึ้น error ที่อ่านไม่รู้เรื่อง

วิธีเปลี่ยนชื่อ กดที่ชื่อ action ด้านบนกล่อง แล้วพิมพ์ทับ

## 5 ค้นหลักสูตรของแถวนี้

ภาษานิพจน์ของ Power Automate **ไม่มีฟังก์ชัน `filter()`** การกรองอาร์เรย์
ต้องทำด้วย action ชื่อ กรองอาร์เรย์ แล้วค่อยหยิบผลลัพธ์ตัวแรกด้วย `first()`

เพิ่ม action **การดำเนินการข้อมูล → กรองอาร์เรย์** ตั้งชื่อ `FilterTraining`

| ช่อง | ค่า |
|---|---|
| จาก | `fx` แล้ววาง `outputs('ReadTrainings')?['body/value']` |
| เงื่อนไข ช่องซ้าย | `fx` แล้ววาง `item()?['รหัสหลักสูตร']` |
| ตัวดำเนินการ | เท่ากับ |
| เงื่อนไข ช่องขวา | `fx` แล้ววาง `items('ForEachRow')?['รหัสหลักสูตร']` |

`item()` หมายถึงแถวของตารางหลักสูตรที่กำลังถูกกรอง
ส่วน `items('ForEachRow')` หมายถึงแถวการลงทะเบียนที่ลูปกำลังวนอยู่
สองตัวนี้คนละตัวกัน ถ้าใช้ `item()` ทั้งคู่ จะเทียบค่าตัวเองกับตัวเองและได้ทุกแถว

จากนั้นเพิ่ม action **เขียน** ชื่อ `Training`

```
first(body('FilterTraining'))
```

`body()` ใช้กับ action ที่คืนผลลัพธ์เป็นเนื้อหา อย่างกรองอาร์เรย์
ส่วน `outputs()` ใช้กับ action ประเภทเขียน สลับกันไม่ได้

## 6 ค้นพนักงานของแถวนี้

action **กรองอาร์เรย์** ชื่อ `FilterEmployee`

| ช่อง | ค่า |
|---|---|
| จาก | `fx` แล้ววาง `outputs('ReadEmployees')?['body/value']` |
| เงื่อนไข ช่องซ้าย | `fx` แล้ววาง `item()?['รหัสพนักงาน']` |
| ตัวดำเนินการ | เท่ากับ |
| เงื่อนไข ช่องขวา | `fx` แล้ววาง `items('ForEachRow')?['รหัสพนักงาน']` |

แล้ว action **เขียน** ชื่อ `Employee`

```
first(body('FilterEmployee'))
```

## 7 นับว่าเหลืออีกกี่วัน

action **เขียน** ชื่อ `DaysAhead`

```
if(empty(outputs('Training')?['วันเริ่ม']), -999, div(sub(ticks(outputs('Training')?['วันเริ่ม']), ticks(outputs('Today'))), 864000000000))
```

ค่า `-999` ใช้กับหลักสูตรที่ยังไม่มีวัน เพื่อไม่ให้สูตรพัง
และเพื่อให้แน่ใจว่าไม่มีทางเท่ากับ 7 หรือ 1

## 8 ตัดสินว่าเป็นรอบไหน

action **เขียน** ชื่อ `Stage`

```
if(and(equals(outputs('DaysAhead'),7),not(equals(toLower(string(items('ForEachRow')?['แจ้งล่วงหน้า 7 วันแล้ว'])),'true'))),'D7',if(and(equals(outputs('DaysAhead'),1),not(equals(toLower(string(items('ForEachRow')?['แจ้งล่วงหน้า 1 วันแล้ว'])),'true'))),'D1',''))
```

ได้ `D7`, `D1` หรือค่าว่าง ค่าว่างแปลว่าแถวนี้ยังไม่ถึงเวลา
หรือส่งไปแล้ว การเช็คช่องที่ติ๊กไว้ตรงนี้ คือตัวกันไม่ให้ส่งซ้ำ
เช็คว่า ไม่เท่ากับ `ใช่` แทน เท่ากับ `ไม่ใช่` ช่องที่ปล่อยว่างจึงนับว่ายังไม่ได้ส่ง
คนเพิ่มแถวไม่ต้องติ๊กอะไรเอง

ช่องสถานะเป็นช่องติ๊ก ตัวเชื่อมต่อ Excel อาจส่งค่าเป็น `true` หรือข้อความ `TRUE` ก็ได้
สูตรจึงแปลงเป็นข้อความตัวเล็กก่อนเทียบกับ `'true'` เสมอ ช่องว่างนับเป็น false
เขียนค่ากลับด้วย `fx` → `true` ไม่ใช่พิมพ์คำว่า true ลงช่อง

## 9 รวมทุกเงื่อนไขเป็นคำตอบเดียว

action **เขียน** ชื่อ `ShouldSend`

```
and(equals(toLower(string(outputs('Training')?['ใช้แจ้งเตือน'])),'true'),equals(outputs('Training')?['สถานะการอนุมัติ'],'อนุมัติ'),equals(outputs('Training')?['สถานะวันที่'],'ยืนยันแล้ว'),equals(outputs('Employee')?['สถานะ'],'ทำงานอยู่'),not(empty(outputs('Employee')?['อีเมล Microsoft 365'])),not(equals(outputs('Stage'),'')))
```

รวมหกเงื่อนไขไว้ที่เดียว แก้ง่ายกว่าการสร้างเงื่อนไขซ้อนกันหกชั้นในหน้าจอ

## 10 เงื่อนไข

| ช่องซ้าย | ตัวดำเนินการ | ช่องขวา |

## 11 แปลงวันเป็น พ.ศ.

action **เขียน** ชื่อ `ThaiDate`

```
if(equals(formatDateTime(outputs('Training')?['วันเริ่ม'],'yyyy-MM-dd'),formatDateTime(outputs('Training')?['วันจบ'],'yyyy-MM-dd')),concat(formatDateTime(outputs('Training')?['วันเริ่ม'],'dd/MM/'),add(int(formatDateTime(outputs('Training')?['วันเริ่ม'],'yyyy')),543)),if(equals(formatDateTime(outputs('Training')?['วันเริ่ม'],'yyyy-MM'),formatDateTime(outputs('Training')?['วันจบ'],'yyyy-MM')),concat(formatDateTime(outputs('Training')?['วันเริ่ม'],'dd'),'-',formatDateTime(outputs('Training')?['วันจบ'],'dd/MM/'),add(int(formatDateTime(outputs('Training')?['วันจบ'],'yyyy')),543)),concat(formatDateTime(outputs('Training')?['วันเริ่ม'],'dd/MM/'),add(int(formatDateTime(outputs('Training')?['วันเริ่ม'],'yyyy')),543),' - ',formatDateTime(outputs('Training')?['วันจบ'],'dd/MM/'),add(int(formatDateTime(outputs('Training')?['วันจบ'],'yyyy')),543))))
```

อบรมวันเดียวได้ `29/09/2569` หลายวันในเดือนเดียวกันได้ `29-30/09/2569`
ข้ามเดือนหรือข้ามปีได้ `30/09/2569 - 01/10/2569` เพราะถ้าย่อแบบเดียวกัน
จะออกมาเป็น `30-01/10/2569` ซึ่งอ่านเป็นวันที่ 30 ต.ค. ถึง 1 ต.ค.

## 12 ส่งการ์ด

เพิ่ม action **Microsoft Teams → Post adaptive card in a chat or channel**

| ช่อง | ค่า |
|---|---|
| Post as | Flow bot |
| Post in | Chat with Flow bot |
| Recipient | สูตร `outputs('Employee')?['อีเมล Microsoft 365']` |

## 13 ติ๊กว่าส่งแล้ว

เพิ่ม **เงื่อนไข** ชื่อ `IsD7`

| ช่องซ้าย | ตัวดำเนินการ | ช่องขวา |
|---|---|---|
| `outputs('Stage')` | เท่ากับ | `D7` |

**กิ่งถ้าใช่** เพิ่ม **Excel Online (Business) → Update a row**

| ช่อง | ค่า |
|---|---|
| Location, Document Library, File | เหมือนเดิม |
| Table | Enrollments |
| Key Column | รหัสการลงทะเบียน |
| Key Value | สูตร `items('ForEachRow')?['รหัสการลงทะเบียน']` |
| แจ้งล่วงหน้า 7 วันแล้ว | `fx` `true` |

ช่องอื่นของ Update a row **เว้นว่างไว้ทั้งหมด** ถ้ากรอกจะไปทับข้อมูลเดิม

**กิ่งถ้าไม่ใช่** ทำเหมือนกัน แต่เปลี่ยนเป็นช่อง `แจ้งล่วงหน้า 1 วันแล้ว`

**บันทึก** แล้ว **ทดสอบ → ด้วยตนเอง → เรียกใช้โฟลว์**

ลำดับที่ต้องผ่าน

| ครั้ง | ต้องเห็น |
|---|---|
| 1 | ได้การ์ดใน Teams ภายในหนึ่งนาที |
| 2 | เปิดไฟล์ ตรวจว่า `แจ้งล่วงหน้า 7 วันแล้ว` ของแถวนั้นเป็น `ใช่` |
| 3 | สั่งรันซ้ำ ต้อง **ไม่** ได้การ์ดอีกใบ |

ครั้งที่ 3 คือการพิสูจน์ว่าตัวกันส่งซ้ำทำงาน ถ้าได้การ์ดซ้ำ
แปลว่าขั้นที่ 13 ไม่ได้เขียนกลับลงไฟล์ ต้องแก้ก่อนไปต่อ

## ถ้ารันสำเร็จแต่ไม่ได้การ์ด

ระบบตั้งใจให้เงียบเมื่อไม่มีอะไรต้องส่ง จึงต้องไล่ดูว่าเงื่อนไขไหนไม่ผ่าน

เปิดประวัติการรัน กดเข้าไปใน `ForEachRow` เลือกรอบที่เป็นแถวทดสอบ
แล้วดูค่าที่ออกมาจากแต่ละ action

| ดูที่ | ค่าที่ถูกต้อง | ถ้าผิด แปลว่า |
|---|---|---|
| `FilterTraining` | ต้องได้ 1 แถว | รหัสหลักสูตรในสองชีตไม่ตรงกัน |
| `Training` | ต้องไม่ใช่ null | `FilterTraining` ไม่เจอแถว |
| `Employee` | ต้องไม่ใช่ null | รหัสพนักงานไม่ตรงกัน |
| `DaysAhead` | ต้องเป็น 7 | วันเริ่มผิด หรือ DateTime Format ไม่ได้ตั้ง ISO 8601 |
| `Stage` | ต้องเป็น D7 | ช่องแจ้งล่วงหน้าถูกติ๊กเป็น ใช่ ไปแล้ว |
| `ShouldSend` | ต้องเป็น true | เงื่อนไขใดเงื่อนไขหนึ่งในหกข้อไม่ผ่าน |

ถ้า `DaysAhead` ออกมาเป็นตัวเลขใหญ่มากอย่าง 46000 แปลว่าลืมตั้ง
DateTime Format เป็น ISO 8601 ในตัว `ReadTrainings`

## ลำดับ action ในลูป สรุป

```
ForEachRow
  FilterTraining   กรองอาร์เรย์
  Training         เขียน
  FilterEmployee   กรองอาร์เรย์
  Employee         เขียน
  DaysAhead        เขียน
  Stage            เขียน
  ShouldSend       เขียน
  CheckSend        เงื่อนไข
    กิ่งจริง
      ThaiDate     เขียน
      SendCard     โพสต์การ์ดในแชทหรือแชนเนล
      IsD7         เงื่อนไข
        กิ่งจริง   MarkD7  Update a row
        กิ่งเท็จ   MarkD1  Update a row
```

## หลังผ่านแล้ว

เปิด Concurrency Control ของ `ForEachRow` ตั้งเป็น 10
เพื่อให้ส่งหลายคนพร้อมกันได้ ห้ามเกิน 10 เพราะการเขียนกลับเข้า Excel
พร้อมกันมากเกินไปจะชนกัน

ตอนทดสอบให้ปิดไว้ก่อน เพราะลูปแบบทีละแถวไล่ดูปัญหาง่ายกว่ามาก
