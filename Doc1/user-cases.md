# กรณีใช้งานและการทดสอบ Rev2

แต่ละกรณีบอกว่าผู้ดูแลกรอกอะไร ระบบทำอะไร และทดสอบอย่างไร
ช่อง "ตรวจแล้ว" บอกว่าตรวจอะไรไปแล้วนอก Excel และอะไรต้องทดสอบในระบบจริง

ผู้ดูแลกรอกแค่ชีต `หลักสูตร` กับ `พนักงาน` ชีตอื่นระบบทำเองหรือเป็นสูตร

## ผู้ดูแลทำอะไรบ้าง

| กรณี | ผู้ดูแลกรอก | ระบบทำ |
|---|---|---|
| 1 เพิ่มหลักสูตรใหม่ | แทรกแถวบนสุดของตาราง ใช้รหัสจากช่อง รหัสหลักสูตรถัดไป ในชีตภาพรวม กรอก ปี หัวข้อ สถานะการอนุมัติ ติ๊ก ใช้แจ้งเตือน | สถานะวันที่ เป็น ยังไม่กำหนดวัน ชั่วโมงรวม ใช้จำนวนชั่วโมงตามแผน |
| 2 เลือกผู้เข้าอบรม | ติ๊กคนในแถวหลักสูตร ติ๊กได้หลายคน | Flow C สร้างแถวผู้เข้าอบรมภายในหนึ่งชั่วโมง หรือทันทีถ้ากดเรียกใช้ |
| 3 ได้วันอบรมแล้ว | กรอก วันเริ่ม วันจบ ช่วงเวลา สถานที่ หรือลิงก์ | สถานะวันที่ เป็น ยืนยันแล้ว ชั่วโมงรวม คำนวณจริงหักพักเที่ยง Flow A แจ้ง 7 วันและ 1 วันก่อน |
| 4 อบรมจบ | ไม่ต้องทำอะไร | Flow B ส่งคำขอยืนยันทาง Teams และอีเมล บันทึกคำตอบลงช่องติ๊ก เข้าอบรมแล้ว |
| 5 เพิ่มคนทีหลัง | ติ๊กเพิ่ม | Flow C เพิ่มเฉพาะคนใหม่ ถ้าหลักสูตรเหลือไม่ถึง 7 วัน คนนั้นได้แค่แจ้ง 1 วัน |
| 6 ถอนชื่อก่อนได้รับแจ้ง | เอาติ๊กออก | Flow C ลบแถวของคนนั้น |
| 7 ถอนชื่อหลังได้รับแจ้งแล้ว | เอาติ๊กออก | Flow C ไม่ลบ แถวในชีตผู้เข้าอบรมเป็นสีส้ม ผู้ดูแลลบแถวในชีต ข้อมูลผู้เข้าอบรม เองถ้าต้องการ |
| 8 ยกเลิกหลักสูตร | เอาติ๊ก ใช้แจ้งเตือน ออก | ทุก Flow ข้ามหลักสูตรนี้ ไม่ส่งอะไรอีก ประวัติคงอยู่ |
| 9 เลื่อนวันอบรม | แก้วันเริ่ม วันจบ | แจ้งเตือนคำนวณจากวันใหม่ นัดในปฏิทินที่สร้างไปแล้วยังอยู่วันเดิม ลบเอง |
| 10 พนักงานเข้าใหม่ | เพิ่มแถวในชีตพนักงาน เลือกกลุ่มงาน แล้วแทรกคอลัมน์ในชีตหลักสูตรตามที่ช่อง มีคอลัมน์ในหลักสูตร บอก | ชื่อแสดงสร้างเอง ติ๊กได้เมื่อมีคอลัมน์ |
| 11 พนักงานลาออก | เปลี่ยนสถานะเป็น ลาออก | ทุก Flow หยุดส่งหาคนนั้น Flow C ไม่แตะแถวของเขา ประวัติคงอยู่ |
| 12 คนไม่มีอีเมล | ไม่ต้องทำอะไร | บันทึกประวัติได้ ไม่ส่งข้อความหา ผู้ดูแลแจ้งเอง |
| 13 แก้ผลที่พนักงานตอบผิด | ชีต ข้อมูลผู้เข้าอบรม แก้ช่องติ๊ก เข้าอบรมแล้ว และ ช่องทางที่ยืนยัน | Dashboard เปลี่ยนตาม |
| 14 ดูสรุป | ชีตภาพรวม เลือกคนและปี | สรุปรายปี อดีต ปัจจุบัน อนาคต และประวัติรายคน |

## ตรวจแล้วนอก Excel (24 ก.ย. 2569)

คำนวณสูตรทั้งไฟล์ด้วยเครื่องคำนวณสูตร หลังแปลงอ้างอิงตารางเป็นช่วงเซลล์ธรรมดา

| ตรวจ | ผล |
|---|---|
| ชีตผู้เข้าอบรมเรียงหลักสูตรใหม่ก่อน 235 แถว ครบ | ผ่าน TR-2569-037 อยู่บนสุด TR-2568-006 ล่างสุด |
| ช่องติ๊กในชีตหลักสูตรตรงกับแถวผู้เข้าอบรมทุกแถว | ผ่าน 235 ติ๊ก 235 แถว ยังติ๊กอยู่ เป็น TRUE ทุกแถว |
| พนักงานทุกคนมีคอลัมน์ในชีตหลักสูตร | ผ่าน ✓ ทั้ง 27 คน |
| รหัสหลักสูตรถัดไป | ผ่าน TR-2569-038 |
| สรุปรายปีและประวัติรายคน | ผ่าน ตรงกับที่คำนวณแยกด้วย Python |

ต้องทดสอบในระบบจริง Excel บนเว็บกับ Power Automate จำลองไม่ได้

## ทดสอบในระบบจริง

ใช้หลักสูตร TR-2569-006 (Test) และบัญชี account@ ห้ามใช้หลักสูตรจริง

### Flow C

| ขั้น | ทำ | ต้องเห็น |
|---|---|---|
| C1 | แถว TR-2569-006 ติ๊ก purchase กานต์ธีรา แล้วกดเรียกใช้ Flow C | ชีตผู้เข้าอบรมมีแถว TR-2569-006 purchase กานต์ธีรา อยู่ใกล้บนสุด กลุ่มงาน OF ช่องติ๊กว่าง |
| C2 | กดเรียกใช้อีกครั้งโดยไม่แก้อะไร | ไม่มีแถวซ้ำ ในประวัติการรัน added = 0 |
| C3 | เอาติ๊ก กานต์ธีรา ออก แล้วเรียกใช้ | แถวของกานต์ธีราหายไป removed = 1 |
| C4 | เอาติ๊ก สาริศา ออก แล้วเรียกใช้ | แถวสาริศาไม่หาย เพราะได้รับแจ้งไปแล้ว แถวเป็นสีส้ม ติ๊กกลับ แล้วสีส้มหาย |
| C5 | ในแถวใหม่จาก C1 ดูคอลัมน์สูตรท้ายตารางในชีต ข้อมูลผู้เข้าอบรม | รหัสการลงทะเบียน รหัสพนักงาน ปีของหลักสูตร หัวข้อหลักสูตร มีค่า |

C5 สำคัญที่สุด ถ้าว่าง แปลว่าตารางไม่เติมสูตรให้แถวที่ Flow เพิ่ม ต้องแก้ Flow C ก่อนใช้จริง

### Flow A และ B หลังแก้สูตรช่องติ๊ก

| ขั้น | ทำ | ต้องเห็น |
|---|---|---|
| A1 | TR-2569-006 วันเริ่มเป็นวันนี้ + 7 วันจบวันถัดไป เอาติ๊ก แจ้ง 7 วัน ของสาริศาออกในชีต ข้อมูลผู้เข้าอบรม แล้วรัน Flow A | การ์ดและอีเมลมาครั้งเดียว ช่องแจ้ง 7 วันติ๊กเอง |
| A2 | รัน Flow A ซ้ำ | ไม่มีการ์ดซ้ำ |
| B1 | TR-2569-006 วันเริ่มและวันจบเป็นเมื่อวาน เอาติ๊ก ขอยืนยัน และ เข้าอบรมแล้ว ออก แล้วรัน Flow B | คำขอใน Teams Approvals และอีเมล |
| B2 | กด เข้าอบรมแล้ว ในอีเมล | Teams ขึ้นว่าตอบแล้ว ช่อง เข้าอบรมแล้ว ติ๊ก ช่องทางที่ยืนยัน = Approvals |
| B3 | รัน Flow B ซ้ำ | ไม่มีคำขอซ้ำ |

### ปิดท้าย

เอาติ๊ก ใช้แจ้งเตือน ของ TR-2569-006 ออก เมื่อทดสอบครบ ก่อนเปิดใช้จริง
